# Pocket Pantry

Pocket Pantry is a tiny Python pantry list for a shared kitchen. It stores items in a local JSON file and has no server or accounts.

```sh
python3 pantry.py add rice 2
python3 pantry.py list
python3 pantry.py use rice 1
```

See [the command guide](docs/commands.md) for the exact behaviour. This small repository is managed by the CAB432 Repository Custodian agent for issue triage and documentation updates.
